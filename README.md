# IT Destek & Sunucu Takip Paneli

C# ASP.NET Core Minimal API ve MySQL kullanılarak geliştirilmiş IT destek kayıt ve sunucu durum takip paneli.

## 🛠️ Teknolojiler
- **Backend:** C# (.NET Minimal API)
- **Database:** MySQL / MariaDB (Dapper ORM)
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)

## 🚀 Özellikler
- Sunucu durumlarını anlık güncelleme (Online/Offline)
- Arıza biletleri (ticket) oluşturma ve silme
- REST API standartlarına uygun HTTP metotları (`GET`, `POST`, `PUT`, `DELETE`)
